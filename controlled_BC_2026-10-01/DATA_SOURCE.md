# Джерело даних

Історичний імпорт: chrico03, [Railroad Accident & Incident Data, Kaggle](https://www.kaggle.com/datasets/chrico03/railroad-accident-and-incident-data). Вихідний збережений файл: `Rail_Equipment_Accident_Incident_Data.csv`, 215 849 записів, 160 полів. У локальній MariaDB було додано `raw_id` як стабільний ключ. Контрольна сума історичного CSV і спосіб відновлення нумерації наведені в `C/source_manifest.json`; номер версії Kaggle під час первинного завантаження не був зафіксований.

Першоджерело за предметним змістом: Federal Railroad Administration, [Rail Equipment Accident/Incident Data (Form 54)](https://catalog.data.gov/dataset/rail-equipment-accident-incident-data-form-54). Каталог Data.gov позначає його як public і посилається на [правила використання творів уряду США](https://www.usa.gov/government-works). Це не означає, що поточна офіційна таблиця тотожна історичній копії Kaggle, і не поширює ті самі умови на сторонні PDF чи публікації. Сторінка Kaggle не надала доступного текстового підтвердження власної ліцензії під час цього аудиту; ліцензію CC0 у цьому пакеті не приписано.

У пакет включено тільки фактичні поля, необхідні для перевірки перетворення, без наративів, персональних даних з описів і PDF:

| Поле пакета | Вихідне поле |
|---|---|
| raw_id | Доданий ключ локального імпорту |
| report_year | Report Year |
| track_type | Track Type |
| damage_text | Total Damage Cost |
| injured_text | Total Persons Injured |
| hazmat_released_text | Hazmat Released Cars |

`Hazmat Released Cars` позначає кількість вагонів із витоком небезпечних речовин, не кількість випадків витоку. Запис є звітним рядком, не гарантовано окремою аварією. Form 54 залежить від чинного для року порога звітних збитків; порівняння років також залежить від правил звітності.

Вибірка B: перші 1 000 записів за `raw_id` із `Accident Type = 'Derailment'` та `Report Year IN ('2018','2019','2020','2021','2022')`. SQL міститься в `B/source_manifest.json`. C охоплює всі записи історичної таблиці. Дані не очищували, не збагачували і не дедуплікували; числові перетворення є частиною тестового правила.
