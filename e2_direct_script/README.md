# Direct чи Script: два експерименти з обробки даних

Цей пакет містить лише матеріали експериментів E2 на вибірках із 250 та 1 000 записів. Статті, рисунки, чернетки та інші експерименти до нього не включено.

## Мета експериментів

Експерименти перевіряють два способи виконання однакової задачі перетворення даних:

- **Direct:** велика мовна модель самостійно формує похідні значення для кожного рядка вхідних даних.
- **Script:** велика мовна модель створює програму, а програма виконує перетворення записів; модель отримує результат для подальшої інтерпретації.

Порівнювалися три механізми організації роботи:

- **M2:** інтерактивний Codex;
- **M3:** окремий процес Codex CLI;
- **M4:** процес на основі OpenAI API.

Експериментальна конфігурація моделі: `gpt-5.6-terra`, рівень міркування `high`.

## Вміст пакета

1. `250/task.txt` та `1000/task.txt` — опис правил задачі для відповідних серій.
2. `250/input.json` та `1000/input.json` — вхідні записи.
3. У папках `m2-direct` ... `m4-script` містяться результати відповідних запусків у `result.csv`.
4. У папках режиму Script файл `generated.js` містить програму, фактично створену моделлю.
5. `metrics.json` містить показники токенів і розрахованої вартості; `usage_evidence.json` — витяг зі збереженого джерела цих показників.
6. У серії 1 000 записів файл `interpretation.txt` містить підсумкову інтерпретацію.
7. Кореневий файл `results.csv` містить зведення всіх 12 виконань.

Файл `prompt.txt` додано лише в тих випадках, де збережений вихідний аналітичний запит був доступний. Файл `task.txt` описує правила експерименту, але не видається за дослівно відновлений запит. У `provenance.json` явно зазначено, для яких виконань доступний вихідний запит. Особисті локальні шляхи замінено на `<PROJECT>` і `<LOCAL_USER>`.
