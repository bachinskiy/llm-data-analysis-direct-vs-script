# Direct чи Script: два експерименти з обробки даних

Цей пакет містить **лише досліди на 250 та 1 000 записах**.
Статті, рисунків, чернеток та інших експериментів тут немає.

## Що перевірялося

Однакові записи обробляли у двох режимах:

- **Direct:** модель сама формує похідні значення кожного рядка.
- **Script:** модель пише програму, а програма обробляє записи.

M2 — інтерактивний Codex; M3 — окремий Codex CLI;
M4 — OpenAI API. Заявлена модель: gpt-5.6-terra, reasoning high.

## Як подивитися

1. Відкрити `250/task.txt` або `1000/task.txt`: опис задачі.
2. Відкрити `input.json` у тій самій папці: вхідні записи.
3. У папках `m2-direct` … `m4-script` подивитися `result.csv`.
4. У Script-папках `generated.js` — фактично згенерована програма.
5. `metrics.json` містить токени й вартість; `usage_evidence.json` —
   відповідний витяг зі збереженого джерела лічильників.
6. У серії 1000 файл `interpretation.txt` містить підсумкову відповідь.
7. `results.csv` — одна підсумкова таблиця всіх 12 виконань.

`prompt.txt` включено там, де збережений аналітичний запит знайдено.
`task.txt` — опис правил, а **не нібито відновлений дослівний запит**.
У `provenance.json` явно зазначено наявність оригінальних запитів.
Особисті шляхи замінено на `<PROJECT>` / `<LOCAL_USER>`.

## Як перевірити самостійно

Потрібен Python 3.10 або новіший, без додаткових бібліотек:

```sh
python verify.py
```

Скрипт незалежно обчислює очікувані значення всіх семи полів,
перевіряє кількість і порядок рядків у кожному CSV, зіставляє usage
із витягами та перераховує USD. Перезаписує тільки `results.csv`.
API-ключ, БД та інтернет не потрібні; згенеровані програми він не запускає.

## Що означають результати

Для **250 рядків** порівнюється лише успішне перетворення.
Для **1000 рядків** — перетворення плюс підсумкова інтерпретація.
Ці дві серії не слід безпосередньо порівнювати як незмінний протокол,
у якому змінився тільки розмір даних.

USD — розрахунок за історичними ставками з `pricing.json`, не рахунок
підписки. Збережений usage можна перерахувати, але архів не є незалежною
атестацією провайдера. Нові модельні запуски можуть мати інші токени.

Ранні невдалі спроби N250 враховано не повністю: usage обрізаного
M4 Direct не збережено; відома невдала Script-спроба мала 942 токени
і 0,007984 USD понад успішне виконання. Не називати цю серію повною
вартістю всіх спроб. Новий дослід N1000 має по одному успішному
модельному виконанню кожного етапу; підготовчі збої CLI/BOM не входять у USD.

Правильні рядки не доводять безпомилковості пояснень. Зокрема, M2 N1000
називає показник Hazmat Released Cars «витоками», хоча це кількість вагонів.
Підсумковий агрегат N1000 для всіх режимів обчислював спільний перевіряльник.
M2 продовжував чат; M3/M4 інтерпретували в новому виклику. Кеш не вирівнювали.
У N250 M4 Direct повертав JSON, який збережено як CSV без зміни значень;
у N1000 всі Direct-виходи були CSV. Згенеровані програми мають спільний
контракт рядків, але вимоги до допоміжного summary не були тотожними.
